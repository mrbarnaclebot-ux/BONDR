## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env -> Surfpool process | The Helius key is handed to a third-party binary as its upstream |
| GitHub release -> local binary | A downloaded executable runs locally |
| spike -> fork | Sends must only reach 127.0.0.1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12 | Information disclosure | fork.sh argv | mitigate | Key passed only via SURFPOOL_DATASOURCE_RPC_URL env, never --rpc-url; acceptance checks `ps` |
| T-01-13 | Information disclosure | Surfpool logs | mitigate | Logs under gitignored .cache/; fork.sh warns (without echoing) if the key appears |
| T-01-14 | Tampering | Surfpool binary | accept | Official solana-foundation/surfpool release via authenticated `gh`; same source agencybook used; local dev only |
| T-01-15 | Tampering | net guard | mitigate | connect("fork") requires host 127.0.0.1/localhost; mainnet genesis allowed only for a local host |
</threat_model>
