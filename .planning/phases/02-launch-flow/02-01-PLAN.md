## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> web | Public pages; no user input in this plan |
| root .env -> web process | Local secrets file shared with the worker |
| npm registry -> repo | New dependencies installed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Information disclosure | apps/web imports | mitigate | Biome noRestrictedImports allowlist for apps/web (D-15) blocks chain libraries and non-pure core modules at lint time |
| T-02-01-02 | Information disclosure | local web env | mitigate | WEB_ENV allowlist loader in next.config.ts copies only web names from the root .env; no loadEnvFile in web |
| T-02-01-03 | Spoofing | every page | mitigate | X-Frame-Options DENY and frame-ancestors 'none' in next.config.ts headers (clickjacking) |
| T-02-01-04 | Tampering | renders | mitigate | React escaping only; existing Biome noDangerouslySetInnerHtml stays on |
| T-02-01-SC | Tampering | pnpm installs | mitigate | Exact pins from the 02-RESEARCH Package Legitimacy Audit (all Approved by slopcheck, none ASSUMED or SUS); minimumReleaseAge enforces D-14 |
