## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08-01 | Information disclosure | WORKER_TOKEN | mitigate | Only lib/worker.ts reads it, marked server-only; acceptance greps that no other web file references it |
| T-02-08-02 | Information disclosure | wallet in quote | mitigate | Wallet sent only when consented (PLAT-02) |
| T-02-08-03 | Spoofing | POST /api/quote | mitigate | sameOrigin and JSON-only (CSRF) |
| T-02-08-04 | Denial of service | quote spam to RPC | mitigate | 400 ms client debounce now; per-IP rate limit added to /api/quote in 02-10 |
