| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-10-01 | Tampering | uploaded file | mitigate | Magic-byte type check, 4 MB cap with early 413, SVG refused (V12) |
| T-02-10-02 | Denial of service | Pinata quota and RPC via quote | mitigate | Per-IP and per-wallet fixed-window limits; consent row required before any upload |
| T-02-10-03 | Spoofing | cross-site pin | mitigate | sameOrigin check (CSRF) |
| T-02-10-06 | Denial of service | /api/consent spam | mitigate | rateLimited scope consent, 10 per 10 minutes per IP |
| T-02-10-04 | Information disclosure | Pinata JWT | mitigate | Read only in the server route; errors redact it; never sent to the client |
| T-02-10-05 | Tampering | metadata fields | mitigate | rules.ts on the server; https-only normalized links |
