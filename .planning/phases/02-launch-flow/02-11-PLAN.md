Purpose: LAUNCH-03's transaction exists before Phantom opens, built only where the seed lives (FEE-10, D-06). Sign order A (D-12) needs the stored bytes for the byte compare in 02-12.
Output: prepare module and route, web proxy, and a devnet driver proving size and one real prepare.
</objective>
