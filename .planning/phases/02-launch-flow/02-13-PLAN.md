## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/launch/submit | Signed wire is untrusted (worker verifies) |
| browser -> /api/launch/{id} | Public read of one launch's public fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13-01 | Information disclosure | GET /api/launch/{id} | mitigate | Returns LaunchView public fields only (no message or signed bytes); random 128-bit id; wallet never in a URL |
| T-02-13-02 | Spoofing | POST submit | mitigate | sameOrigin, JSON-only, rate limit; the worker's cosign is the real gate |
| T-02-13-03 | Tampering | reload double-sign | mitigate | Stored launchId restores step 4 and never re-signs a submitted launch |
| T-02-13-04 | Spoofing | clickjacking the sign step | mitigate | frame-ancestors none and X-Frame-Options DENY from 02-01 |
| T-02-13-05 | Tampering | coin name in success copy | mitigate | React escaping only |
</threat_model>
