## Phase Goal

**As a** trader, **I want to** see live lists and charts of every BONDR coin, **so that** I can find and judge coins.

<objective>
Wave 0 for the indexer: the devnet trade generator, the fixture capture tool, the websocket URL builder and a probe that settles research assumptions A1 (logsSubscribe sees ALT-loaded mints), A2 (getSignaturesForAddress(mint) lists pool and multi-hop trades) and A8 (completing a devnet child curve is affordable). Every later parser test and live e2e runs on what this plan captures.

Purpose: decoding and streaming are built against real transactions, not docs (RESEARCH Open Questions 2 and 3, Pitfall 9).
Output: three scripts, wsUrl, a set of committed fixtures, and the probe results with signatures in the summary.
</objective>
