| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Spoofing | forged trade events | mitigate | Events accepted only from an inner instruction of the pump or PumpSwap program whose account 0 is that program's event authority PDA; test with a swapped authority |
| T-03-02-02 | Tampering | non-BONDR coins in lists | mitigate | parseTx emits rows only for mints in the KnownCoin map or the launch mint (D-03) |
| T-03-02-03 | Denial of service | malformed or new event layouts | mitigate | Decoding only through the pinned SDK; unknown names are reported in unknown, never thrown; a decode exception is caught per event |
| T-03-02-04 | Tampering | failed transactions | mitigate | meta.err returns no events (existing rule kept) |
