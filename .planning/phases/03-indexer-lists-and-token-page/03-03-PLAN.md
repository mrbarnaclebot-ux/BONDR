<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL param -> image route | Untrusted mint string |
| web server -> Pinata gateway | Server-side fetch of a user-uploaded image |
| stored metadata -> card text | Name and symbol came from users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering (SSRF) | fetchCardImage | mitigate | Host fixed to PINATA_GATEWAY, CID must match /^[A-Za-z0-9]+$/, https only, no redirects followed to other hosts (redirect: "error") |
| T-03-03-02 | Denial of service | card render | mitigate | 5 s timeout, 2 MB cap, content-type allowlist, immutable cache for known coins, proxy.ts read limit on /coin/:path* |
| T-03-03-03 | Tampering | coin name injection | mitigate | Satori renders text nodes, not HTML; mint validated with BASE58_KEY before the query |
| T-03-03-04 | Information disclosure | external font or emoji fetch | accept | Satori may fetch emoji or non-Latin glyphs from its CDNs server-side (Pitfall 7); failure only drops glyphs; noted in the summary |
| T-03-03-05 | Spoofing | non-BONDR mint card | mitigate | Only landed BONDR launches get a coin card; any other mint gets the site card |
</threat_model>
