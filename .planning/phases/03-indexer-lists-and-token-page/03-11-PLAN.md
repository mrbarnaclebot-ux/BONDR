## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/coins and / | Untrusted sort and page params |
| stored metadata -> cards | User-supplied names, symbols, image CIDs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11-01 | Tampering | sort and page params | mitigate | Enum and integer range checks, 400 otherwise; parameterized SQL with fixed ORDER BY branches (no interpolated column names) |
| T-03-11-02 | Denial of service | list queries | mitigate | 10 s per-process cache per (sort, page), page cap 99, proxy read limit on / and /api/coins |
| T-03-11-03 | Tampering | coin name or image injection | mitigate | React escaping; image src only through imageUrl's CID check to the Pinata gateway or ipfs.io (CSP img-src unchanged) |
| T-03-11-04 | Information disclosure | worker status at render | accept | Status is already public at /api/status |
</threat_model>
