# Phase 3 — UI Design Contract

> Visual and interaction contract for the home lists, search, token page chart and trade feed, and the share card. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This spec extends `.planning/phases/02-launch-flow/02-UI-SPEC.md` (approved, implemented). Every Phase 2 token, type role, color rule, component, motion rule and accessibility rule still applies and is not repeated here unless Phase 3 changes how it is used. Layout source of truth: the approved round 2 mockups `home.html` and `token.html`. Locked decisions: `03-CONTEXT.md` D-01 to D-21. Where this spec departs from a mockup, the row says why.

## Color

Unchanged palette and token mapping (02-UI-SPEC Color, `tokens.css`). Never write `accent` meaning the brand green in code; write `leaf`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1a1a1a` with the two fixed light leaks and film grain | Page background |
| Secondary (30%) | `surface`, `surface-2`, `surface-3`; card gradient `surface-2` to `surface` at 60%; chart panel gradient plus a top-right radial (leaf 9%) | Coin cards, chart panel, bond panel, trades panel, search input, seg control |
| Accent (10%) | `#56c44a` (`leaf`) | Only the elements listed below |
| Brand primary | `#a2d59c` (`mint`) | Links, seg indicator fill, last-price line and label on the chart, "On curve" tag, "Launch" feed label, bonded marker on the chart, hover border on quiet buttons and arrows |
| Destructive | `#f0705e` | Negative 1h change, "Sell" label, down candles and down volume bars, sell flash tint, error callouts. Never decoration |
| Warn | `#e2c56b` | Launches paused banner (home), DEVNET badge |

Accent `#56c44a` is reserved for (Phase 2 items 1-8 still apply; Phase 3 adds 9-15):

9. The word "bond." in the hero headline and its text glow
10. Positive values: 1h change above zero (text and its 12% pill), the "Buy" label in the trade feed, up candles and up volume bars, the buy flash tint on live values
11. The bond glyph: node A, the fill gradient end, the bonded node B and its ring; the "Bonded" tag (leaf wash, leaf 45% border)
12. The live dot: hero pulse line and the Trades "Live" indicator
13. Coin card hover ring (`0 0 0 1px` leaf 35%) and focus ring
14. The new-launch glow (`--glow`) on a card that just slid into Latest, for 3 seconds
15. Primary CTA fill "Launch a coin" in the hero and the empty states

Zero change (`0.0%`) and missing values render in muted text, never accent or destructive.

## Motion

CSS only, Phase 2 tokens (`--ease-out`, `--ease-spring`, `--dur`). Phase 3 adds:

| Element | Motion |
|---------|--------|
| Hero art | Muted, looping, `playsinline` 6s video (`hero-bond.mp4`, poster `hero-bond-poster.jpg`) with `breathe` 14s alternate (`scale(1.02)` to `scale(1.08) translateX(-1.5%)`); 16 motes drifting up (7-15s linear) |
| Section head reveal | Pure CSS scroll-driven fade and 18px rise (`animation-timeline: view()`, range `entry 0% entry 40%`) inside `@supports (animation-timeline: view())`. Headings are fully visible without support. Not applied to cards |
| Coin card hover | `translateY(-6px)` 560ms spring, shadow 400ms ease-out; avatar `translateY(-4px) rotate(-4deg)` 560ms spring; art bleed `scale(1.3) rotate(4deg)` 900ms ease-out |
| Live value flash | On a trade, the changed numbers (market cap, 1h change, curve %) get a background tint from leaf 32% (buy) or destructive 32% (sell) to transparent over 800ms ease-out. Direction is the trade side (D-15), not the sign of the change |
| New launch in Latest | `rise` 700ms spring, then `--glow` held 3s and faded over 600ms |
| Re-rank | Cards reorder in place with no animation (D-12 keeps it to once a minute; motion would draw the eye to a jump) |
| Seg indicator | Slides between equal-width buttons: `width: calc((100% - 8px) / n)`, `transform: translateX(calc(var(--i) * 100%))`, 520ms spring. No JS measuring |
| Trending arrows | `scrollBy` two card widths plus gap, `behavior: smooth`; hover `scale(1.08)` 420ms spring, mint border |
| Bond glyph | Fill draws from 0 (`scaleX`) 1400ms spring on first render only; at 90% and above node B pulses (1.8s infinite); at 100% a ring radiates from node B (2.4s infinite) |
| Feed row insert | New top row `rise` 640ms spring plus the buy or sell flash on the row |
| Chart | No animation (lightweight-charts draws immediately) |

`prefers-reduced-motion: reduce` (global override from Phase 2 stays) and, explicitly:
- Hero: no video element is rendered; the still `hero-bond.jpg` (with `srcset` 960w / 1920w) shows with no `breathe`. Motes are not rendered.
- Flashes: the flash class is never added (check the media query in JS, do not rely on the 1ms override).
- New-launch glow: shown statically for 3s, no rise.
- Bond glyph: drawn at its final width; no pulse, no ring (bonded node B stays filled).
- Trending arrows scroll with `behavior: "auto"`.
- Section head reveal: not applied.
- Live dots are static.

## Home

### Paused banner

Shown above the hero when launches are paused (kill switch or BONDR awaiting migration). Read once from the existing status source at server render; the home page does not poll it. Warn callout style from `home.html` (`warn` 10% into `surface`, warn 40% border, pause icon), `role="status"`. While paused, the hero "Launch a coin" button renders as the Phase 2 disabled button "Launches paused".

### Hero

- Left column: h1 "Built to bond." (Hero role, "bond." in leaf with `text-shadow: 0 0 60px` leaf 45%), lede (Body, 1.6 line height, max 46ch, text 82% into background), CTA row (32px top margin), pulse line (24px top margin).
- CTA row: primary lg "Launch a coin" (to `/launch`) and quiet lg "See all coins" (in-page link to `#all-coins`).
- Pulse line (D-09): leaf live dot plus Label muted text with mono numbers in foreground.
- Art: `aria-hidden`, absolutely positioned, mask `linear-gradient(90deg, transparent 12%, #000 52%)` intersected with `linear-gradient(0deg, transparent 2%, #000 34%)`, `object-position: 86% 50%`. Copy `hero-bond.jpg`, `hero-bond-poster.jpg` and `hero-bond.mp4` from `.planning/mockups/assets/` to `apps/web/public/art/` (all same-origin; CSP `default-src 'self'` covers media). The video is `preload="metadata"`, `muted`, `loop`, `playsinline`, `autoplay`, no controls, no audio track needed.

### Trending (LIST-01)

- Section head: Display h2 "Trending" plus caption (Label, muted) on the left; arrow buttons on the right (760px and up).
- Scroller: `role="region"`, `aria-label="Trending coins"`, `tabindex="0"`, CSS grid `grid-auto-flow: column`, `grid-auto-columns: 288px` (80% below 760px), 16px gap, `scroll-snap-type: x mandatory`, `scroll-padding-inline: var(--gutter)`, bleeds to the viewport edge with negative gutter margins, scrollbar hidden, `overscroll-behavior-x: contain`.
- Mouse drag scrolls (pointer events, mouse only; touch and wheel scroll natively); a drag over 4px suppresses the click that ends it. Snap is off while dragging.
- Up to 10 cards. Ranking (D-03, D-13): quote volume in the last hour; if no coin traded in the last hour, 24h volume; if none in 24h, the latest launches. The caption and the top-right chip follow the mode (see copy).
- Rank chip "#{n}" only in the two volume modes. Volume chip "{vol} SOL 1h" or "{vol} SOL 24h"; in the latest-launches mode the chip shows age instead.
- Section hidden entirely when there are no coins at all (the All coins empty state covers it).
- Arrows: `aria-label` "Scroll trending left" / "Scroll trending right"; `aria-disabled="true"` at each edge (8px tolerance), opacity 0.35, click does nothing, still focusable.

### All coins (LIST-02, LIST-03, LIST-05)

- Section head: Display h2 "All coins" (`id="all-coins"` on the section), caption.
- Controls row: seg control `role="group"`, `aria-label="Sort coins"`, buttons `aria-pressed`: "Top", "Latest", "Oldest". Search label wrapping the icon and `<input type="search">`.
- Grid: `<ol aria-label="Coins">`, one `<li>` per card.
- Page size 50 cards. Below the grid, when more exist: quiet button "Show more coins" (full width below 560px, centered otherwise); while loading "Loading…" and disabled; it appends the next 50.
- Sorting (D-03): Top by market cap, Latest by launch time newest first, Oldest by launch time oldest first. Ties break by launch time, newest first.
- Switching tabs or searching keeps the current cards on screen at 60% opacity with `aria-busy="true"` on the `<ol>` until the new list arrives, then swaps. No skeletons.

### Search (LIST-05)

| Input | Behaviour |
|-------|-----------|
| Empty | The tab list |
| 1 character | Nothing happens (too broad); the tab list stays |
| 2+ characters | Debounced 300ms; matches name or symbol (case-insensitive, contains) or mint (prefix); results sorted by the active tab |
| A full valid mint of a BONDR coin, pasted or typed | Navigates straight to `/coin/{mint}` |
| A full valid mint that is not a BONDR coin | Mint empty state |
| No match | No-match empty state |
| Escape or the clear button (X, 44px below 768px, 32px at 768px and up, `aria-label="Clear search"`) | Clears the query and restores the tab list; focus stays in the input |

An sr-only `aria-live="polite"` line after each search: "{n} coins match" / "1 coin matches" / "No coins match". Live updates (below) apply to search results too, but new launches are not inserted while a query is active.

### Coin card (LIST-04)

One `<a href="/coin/{mint}">` per card, `draggable="false"`.

| Part | Trending card | Grid card (560px and up) | Grid card (below 560px) |
|------|---------------|---------------------------|--------------------------|
| Art head | 150px tall, bleed, rank chip top-left, volume chip top-right, avatar 72px bottom-left at 16px | 104px tall, bleed, age chip top-right, avatar 56px bottom-left at 12px | 108px wide column, avatar 56px centered, age chip bottom-left at 8px |
| Name row | Name (20px) + symbol | Name (20px) + symbol | Same |
| Value row | Market cap "{mcap} SOL" (Emphasis mono), right: 1h change pill. Under the cap: "{age} old" (Caption muted) | Market cap + change pill. No sub-line (age is in the chip) | Same |
| Bond row | Bond glyph (160x18 viewBox, fills the row) + "curve {pct}%" (Caption, "curve" in UI muted, number mono), or "Bonded" tag at 100% | Same | Same |
| Body padding | 4px top, 16px sides and bottom; 8px gap | Same | 8px vertical, 16px sides |

Coin image: `<img src="{gateway}/ipfs/{cid}" alt="" loading="lazy" decoding="async">` with `object-fit: cover`, for both the avatar and the bleed copy (the browser fetches it once). A CID that fails the existing `/^[A-Za-z0-9]+$/` check renders no image. A failed load hides the `<img>` (`onError`), leaving the `surface-2` block. Never `next/image` (no `remotePatterns`, web WR-07). Images come only from the Pinata gateway or ipfs.io (CSP).

1h change pill: Label mono, 0 / 8px padding with a 24px min-height, pill, `currentColor` 12% fill. Format "+18.2%", "−2.2%" (U+2212), "0.0%". Coins younger than an hour compare against the launch price.

Card accessible name: the link text in reading order (name, symbol, market cap, change, curve). The bond glyph is `role="img"` with `aria-label` "Curve 64.2 percent filled" or "Bonded"; the visible "curve 64.2%" text is `aria-hidden` to avoid reading it twice.

### Live behaviour (D-12 to D-15)

| Event | Lists | Trending |
|-------|-------|----------|
| Trade on a listed coin | Market cap, 1h change and curve % update at once on every card for that coin, with the buy or sell flash | Same, plus the volume chip |
| Re-rank | At most once a minute (60s client tick). The tick re-sorts Top (and Trending) and refreshes ages. If the pointer is over the grid or scroller, or focus is inside it, the re-rank waits until the pointer leaves and focus moves out | Same; the Trending mode and caption can change on the tick |
| New launch | Latest with no query: card inserted at the front with rise and the 3s glow (D-14). The last card is not removed (the list grows). Top and Oldest pick it up on reload or a resync catch-up (accepted 03-14: a new coin ranks near the end of both, past the first 50 cards once the list is longer) | Enters on a re-rank if it ranks |
| Bond (curve complete) | Bond row turns to the "Bonded" tag | Same |
| Connection lost | `EventSource` reconnects on its own; values stay as last shown; on reconnect the page refetches the visible list once to catch up. No indicator on home | Same |

Hero counts (D-09) increment on a new-launch or bond event.

|-------|--------|
