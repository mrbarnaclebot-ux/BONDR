<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> web /api/trade/quote | Untrusted side, mint, amount, slippage |
| web -> worker | Bearer-token private HTTP; worker re-parses everything |
| worker -> Helius | Credits spent per uncached read |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 (T1) | Tampering | parseTrade | mitigate | Digits only, buy 1..MAX_SOL_IN, sell under 2^64, slippage 10..5000, mint in knownCoins, BONDR mint refused; unit tested |
| T-04-02-02 (T6) | Denial of service | /api/trade/quote and readMintState | mitigate | 120/min per IP at web; 2 s single-flight per mint and 60 s configs at worker; only knownCoins mints bound the cache |
| T-04-02-03 (T2) | Spoofing | /trade/balance wallet | mitigate | The worker trusts the wallet only from web, and web sends the session wallet (route lands in 04-03); quote route forwards no wallet at all |
| T-04-02-04 (T9) | Information disclosure | worker logs | mitigate | Every catch path logs through redact (existing http.ts 500 path) |
| T-04-02-05 (T11) | Repudiation | fee rows | mitigate | Panel renders only quote values; no rate constant in web (UI-SPEC rule), grep in acceptance |
</threat_model>
