<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phantom -> browser | The only key that signs; returns the signed wire |
| browser -> web trade routes | Run requests carry no wallet; the session names it |
| e2e -> devnet | Real sim-wallet spend, capped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07-01 (T2) | Spoofing | trade-run request bodies | mitigate | No wallet in any body (acceptance grep); account switch before submit throws switched |
| T-04-07-02 (T3) | Tampering | signing | mitigate | signTransaction only, never signAndSend (D-02); the worker byte compare (04-06) refuses any change |
| T-04-07-03 (T8) | Tampering | unknown result | mitigate | Unknown shows the Solscan link and tells the trader to check before trading again; the browser never resends |
| T-04-07-04 (T10) | Tampering | over-15% impact | mitigate | The anyway label is a second explicit confirmation, Phantom the third; prepare re-simulates with the slippage floor |
| T-04-07-05 | Denial of service | devnet sim wallet | mitigate | Top-up only under 0.03 SOL; spend assertion of at most 0.05 SOL; wallets row removed after |
</threat_model>
