## Phase Goal

**As a** trader, **I want to** buy and sell BONDR coins with SOL in one signature, **so that** I never leave the page.

<objective>
Expose the worker's trade path to consented browsers: the prepare, submit and poll routes, with the guard order every web route follows, proven by an unstubbed Playwright spec that calls the routes directly.

Purpose: these routes are the trust boundary between an untrusted browser and a worker that spends Helius credits and relays signed transactions (T2, T3, T6).
Output: three web routes and trade-routes.e2e.ts.
</objective>
