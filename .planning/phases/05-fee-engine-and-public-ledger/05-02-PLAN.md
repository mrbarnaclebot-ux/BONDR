## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/coin/[mint]/ledger | Untrusted mint and cursor |
| Postgres -> page | Internal rows must not leak |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Information disclosure | ledger read | mitigate | Allowlist `inArray(kind, PUBLIC_KINDS)` plus `state = 'landed'`; detail copied key by key (dBps, tBps, deployer, treasury, deployerAmount, treasuryAmount), never the raw jsonb, so a held reason or a diff never leaves the server |
| T-05-02-02 | Tampering | cursor and mint input | mitigate | BASE58_KEY on the mint (404), strict cursor regex with an INT8_MAX bound (400), parameterized drizzle SQL |
| T-05-02-03 | Denial of service | ledger route on Neon | mitigate | PAGE = 20, first page kept 10 s with the page's existing read; no timer reads |
| T-05-02-04 | Spoofing | Solscan links | mitigate | Links built only by `explorer("tx", signature, net)` from stored signatures; rel and target from TxLink |
</threat_model>
