## Phase Goal

**As a** holder, **I want to** see every fee movement with a transaction link, **so that** I can verify none went to the dev.

<objective>
Build the engine's money core: the ledger store (Postgres and in-memory, same rules), the intent-first `land` pipeline with the ops floor and the mainnet-only Sender path, and the pre-bond jobs collect, split and the window sweep.

Purpose: every later job (forced bond, fallback burn, finalize, batch) sends through `land`, so crash safety, the ops floor and the program allowlist live in one place. The in-memory store lets the fork rows (05-07 on) run the engine's own code.
Output: fee-config.ts, fee-ledger.ts, fee-send.ts, fee-prebond.ts with tests, core sweepIxs.
</objective>

## Trust Boundaries

|----------|-------------|
| worker -> Solana | Engine-signed transfers out of W, the buyback and treasury |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | double send after a crash | mitigate | sign, insertPending, then broadcast; unique-refused intent returns "done" with no broadcast; unknown status is never resent (send.ts rule) |
| T-05-04-02 | Elevation of privilege | wrong destination | mitigate | splitIxs and sweepIxs send only to the derived treasury and buyback ATAs; signTx's checkMessage allowlist; no caller-supplied address reaches these builders |
| T-05-04-03 | Tampering | split sized from W's balance | mitigate | split amount from the collect meta delta only (D-14), asserted by the prebond test |
| T-05-04-04 | Denial of service | ops drained | mitigate | collect minimum per network (D-11); ops floor from postBalances[0] skips non-urgent sends (D-20) |
| T-05-04-05 | Information disclosure | RPC URL or Sender key in logs | mitigate | every logged error passes redact(); Sentry scrub unchanged |
| T-05-04-06 | Spoofing | mainnet Sender reached from devnet | mitigate | urgentBroadcast branches on net; the devnet test asserts fetch is never called; env.ts still refuses mainnet |
</threat_model>
