## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-01 | Repudiation | admin_audit rows edited or deleted after the fact | mitigate | admin_audit_guard trigger refuses DELETE and any UPDATE except pending to a final result with identity columns unchanged; db-admin.test.ts asserts P0001 |
| T-06-01-02 | Tampering | hold or hide flags half set | mitigate | coins_hidden and coins_held CHECKs (both null or both set); db-admin.test.ts asserts 23514 |
| T-06-01-03 | Denial of service | EVACUATE insert refused by the old sig_kind index, nothing sent and nothing reported | mitigate | fee_ledger_sig_kind widened to (signature, kind, coalesce(mint, '')); db-admin.test.ts inserts two mints under one signature |
| T-06-01-04 | Information disclosure | MASTER_SEED_FILE path or seed reaching the dev server env through playwright.config.ts | mitigate | keys.ts derives only the public address; the config sets ADMIN_WALLET (a public key) and never copies rootEnv into process.env; comment states it |
| T-06-01-05 | Elevation of privilege | settings defaults pausing the staging engine | mitigate | every new switch column defaults to true, so the staging engine keeps running (HV-05-01) |
| T-06-01-06 | Denial of service | migration on the shared dev branch | accept | additive columns with defaults, two new tables, a widened check and an index swap; the running Phase 5 worker keeps working |
