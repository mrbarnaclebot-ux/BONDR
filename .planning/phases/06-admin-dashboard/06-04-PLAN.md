## Phase Goal

**As a** platform owner, **I want to** see and fix every coin and job from one dashboard, **so that** nothing needs a manual script.

<objective>
Fix the four latent one-mint assumptions in the fee ledger and send path before any admin action writes multi-mint transactions, and split fee-ledger.ts to make room.

Purpose: these run in the schema waves because EVACUATE (06-22) and the leftover sweep (06-09) depend on them, and a silent `{state: "done"}` with nothing sent is the worst failure mode a break-glass action can have (RESEARCH Pitfalls 3-6). The 0007 index fix landed in 06-01; this plan mirrors it in memory and fixes the code paths.
Output: fee-ledger-memory.ts, the widened keysOf, withSol skip, per-mint landed publish in fee-send and fee-recover, evacuate in reconcile, tests for each.
</objective>
