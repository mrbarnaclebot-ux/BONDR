## Phase Goal

**As a** platform owner, **I want to** see and fix every coin and job from one dashboard, **so that** nothing needs a manual script.

<objective>
Make the engine controllable from outside: split fee-engine.ts, add the stuck-step memory, a result-returning exclusive run on a coin's queue, queue idle waits, and the manual hold flag.

Purpose: the health panel's stuck count (06-08), the W table and timeline stuck states (06-16, 06-17), every admin action's serialization (06-11, 06-13) and EVACUATE's batch waits (06-22) all read or call these. Pitfall 9: enqueue swallows results and is a no-op with the engine off, so admin actions need their own entry point.
Output: fee-boot.ts, Engine additions with tests, FeeCoin.hold and the FeeDeps.allowed type.
</objective>
