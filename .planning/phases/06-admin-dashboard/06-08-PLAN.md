## Phase Goal

**As a** platform owner, **I want to** see and fix every coin and job from one dashboard, **so that** nothing needs a manual script.

<objective>
Open the worker's admin door, fail closed, with its first route: a memory-only health snapshot covering heartbeat, the honest leader-lock row, last runs, RPC stats, the stuck count, switches, the engine and ops flags, the EVACUATE mode and the Sentry count.

Purpose: ADMIN-06 and the worker half of ADMIN-01's allowlist. The console polls health every 10 s, so it must never wake Neon (D-22). The gate wrapper is reused by every later admin route.
Output: env parsing for the three new names, admin-routes.ts gate plus health, rpc-stats.ts, sentry-count.ts, healthSnapshot, the Connection fetch option, the stream mark, all with tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web -> worker /admin/* | Bearer plus the forwarded actor; the worker re-checks the allowlist |
| worker -> Sentry API | Outbound read with a token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08-01 | Elevation of privilege | an admin route reachable without ADMIN_WALLET or with another actor | mitigate | gated wrapper applied in one place for every route; table test over all routes (D-08) |
| T-06-08-02 | Tampering | a leaked WORKER_TOKEN reading health or flipping state | accept | worker is private-network only; health is non-sensitive; state changes need the actor and are audited (06-10); money needs the owner signature (06-13) |
| T-06-08-03 | Information disclosure | SENTRY_READ_TOKEN in logs or errors | mitigate | never logged (env header rule); sentry-count test asserts the token never appears in errors; web forbids the name (06-02) |
| T-06-08-04 | Denial of service | the 10 s poll waking Neon | mitigate | healthSnapshot is memory only; test mocks the db module to throw |
| T-06-08-05 | Denial of service | Sentry API slowness blocking health | mitigate | 60 s cache with one shared promise; failure returns the failed state |
| T-06-08-06 | Elevation of privilege | EVACUATE execution enabled by a typo | mitigate | ADMIN_EVACUATE enum with default simulate, boot fails on other values and on non-devnet "on" (A2) |
</threat_model>
