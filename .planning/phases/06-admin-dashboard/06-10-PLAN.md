## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web -> worker admin routes | Session-only actions (no fresh signature, D-13) |
| worker -> Postgres | Audit rows, hold flags, switch columns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10-01 | Repudiation | a console action with no record | mitigate | every route writes an audit row through the one writer (D-34); tests assert one row per action |
| T-06-10-02 | Tampering | a leaked WORKER_TOKEN flips switches or holds coins | accept | D-13 makes non-transaction actions session-only; the worker is private-network only, needs the actor, and every change is audited and reversible; recorded as an accepted risk (RESEARCH Security Domain) |
| T-06-10-03 | Information disclosure | secrets in audit params or logs | mitigate | callers pass only action inputs; write failures log the SQLSTATE only; test spies on console.error |
| T-06-10-04 | Tampering | release hold re-running a permanent finalize without pre-flight | mitigate | release on a finalize-held coin sets finalize none so the next batch re-runs the full pre-flight (A5); Finalize split with launches.wallet stays the primary release (D-05, D-15) |
| T-06-10-05 | Denial of service | a long re-check holding the web request | mitigate | one status read only (A8); the boot resume owns retries |
| T-06-10-06 | Denial of service | overview reading 500 W accounts | mitigate | W table uses coins.fee_budget; only the selected coin is read live (D-23); one-call tests |
</threat_model>
