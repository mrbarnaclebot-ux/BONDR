## Phase Goal

**As a** platform owner, **I want to** see and fix every coin and job from one dashboard, **so that** nothing needs a manual script.

<objective>

Purpose: ADMIN-03 and ADMIN-04's core. The one FeeDeps.land seam makes simulation cheap and exact per step: the same job runs twice, once captured (simulate) and once gated (execute, 06-13).
Output: admin-sim.ts and admin-actions.ts with tests.
</objective>

- `captureDeps(base: FeeDeps, sink: Step[], watch: Watched): FeeDeps`; `type Step = { ok: boolean; cu: number | null; err: string | null; feeLamports: bigint; pre: AccountSnap[]; post: AccountSnap[]; ixs: TransactionInstruction[] }`; `type Watched = { address: PublicKey; name: string; kind: "sol" | "token"; unit: AdminBalanceRow["unit"] }[]`.

- `runOn<T>(engine: Engine | null, mint: string, fn: () => Promise<T>): Promise<T>` (engine.exclusive when the engine exists, else fn directly, Pitfall 9).
Applicability reasons are codes the UI maps to copy: "not_curve", "below_trigger", "no_child", "not_complete", "not_bonded", "no_failed_sweep", "not_finalized", "no_bondr".

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin route -> engine jobs | Admin runs the same jobs as automation, outside the switches |
| worker -> RPC simulate | Simulation reads chain state; nothing is signed for real |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11-01 | Tampering | simulation sending a real transaction or writing ledger rows | mitigate | captureDeps replaces land and publish and uses mode dry; tests make base land, insertPending and publish throw |
| T-06-11-02 | Elevation of privilege | finalize locking 80% to a wrong deployer | mitigate | finalize_split uses coin.wallet (launches.wallet) only and its allowlist names only that deployer and the treasury (D-15); test |
| T-06-11-03 | Tampering | a simulation corrupting the engine's live coin state | mitigate | capture runs get a shallow copy of the coin; test asserts the engine's coin is unchanged |
| T-06-11-04 | Repudiation | a misleading preview for multi-step actions | mitigate | later steps labeled estimated and re-checked by preflight when sent (OQ1); the dialog says so (06-18) |
| T-06-11-05 | Tampering | an action applied in the wrong state | mitigate | applies() checked at simulate and again at execute (06-13); matrix test |
