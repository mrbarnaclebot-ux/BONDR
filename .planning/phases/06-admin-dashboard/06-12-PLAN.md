<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/admin/{op} | Admin cookie gated; the body is untrusted |
| web -> worker /admin/* | Bearer token plus the actor the web asserts from the cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-12-01 | Spoofing | body-supplied actor | mitigate | forwarder spreads the body first and sets actor from s.wallet last; acceptance grep |
| T-06-12-02 | Tampering | cross-site request to admin ops | mitigate | POST only, sameOrigin 403 before the cookie check, SameSite=Strict cookie (Pitfall 8) |
| T-06-12-03 | Denial of service | the console keeping Neon awake | mitigate | the poll hits only /admin/health (memory); the spec proves zero overview calls on a timer and no polls while hidden (D-02, D-22) |
| T-06-12-04 | Information disclosure | worker internals reaching the browser | mitigate | the forwarder passes only contract codes from worker.ts PASS; failures map to worker_unavailable |
| T-06-12-05 | Elevation of privilege | an unforwarded worker route reachable from the web | accept | only FORWARD names reach the worker; unknown ops answer 404 |
</threat_model>
