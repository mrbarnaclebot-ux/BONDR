## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/admin/switch | Session-gated, no fresh signature (D-13) |
| web -> Postgres admin_audit | Read-only from web; the worker is the only writer (D-34) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-14-01 | Tampering | forged switch flips | mitigate | admin cookie, sameOrigin, rate limit at the web; worker gated() re-checks the actor (D-08, D-11) |
| T-06-14-02 | Repudiation | an unrecorded flip | mitigate | the worker writes one landed audit row per flip (06-10); the spec asserts the row |
| T-06-14-03 | Information disclosure | audit params leaking secrets to the browser | mitigate | params hold only job, enabled, reason or intent id by construction (06-10, 06-13); the page renders copy, not raw params |
| T-06-14-04 | Denial of service | shared switch state breaking parallel specs | mitigate | admin-switch.e2e.ts runs in the serial admin-serial project and restores state (Pitfall 11) |
| T-06-14-05 | Tampering | malformed audit cursor | mitigate | parseAuditCursor returns null and the op answers 400 |
</threat_model>
