<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker intent text -> Phantom | The owner reads and signs the worker's message |
| browser -> /api/admin/execute | Carries only the intent id and the signature |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-18-01 | Spoofing | a client-built message tricking the owner | mitigate | the dialog signs intent.message verbatim; the spec compares bytes; the worker verifies against its stored text (06-13) |
| T-06-18-02 | Tampering | a send after a refused destination | mitigate | no send button renders on refusal; the worker would refuse anyway (no intent is created, 06-13) |
| T-06-18-03 | Repudiation | owner unsure what was sent | mitigate | landed state lists every signature as a TxLink; the audit log reloads after close |
| T-06-18-04 | Denial of service | accidental devnet spend from specs | mitigate | admin-stubs.ts fails the test on any unstubbed simulate, execute or intent call |
| T-06-18-05 | Information disclosure | raw RPC errors in the dialog | mitigate | adminErrorCopy maps codes; unknown codes fall back to the worker_unavailable line |
</threat_model>
