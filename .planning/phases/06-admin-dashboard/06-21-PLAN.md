## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-21-01 | Tampering | malformed signature input | mitigate | base58 length check at the web and the worker route (400) |
| T-06-21-02 | Information disclosure | program ids or raw logs reaching the client bundle | mitigate | the worker returns labelled strings only; check-client-bundle.sh runs in the verify |
| T-06-21-03 | Denial of service | inspector spamming the RPC | mitigate | per-wallet rate limit on every admin op (60 per minute, 06-03); one call per click |
| T-06-21-04 | Tampering | crafted transaction data crashing the decoder | mitigate | each decode is wrapped; a failure yields "Unknown program" or an undecoded line, never a 500 |
