## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pump programs -> worker jobs | A layout change would make every job build wrong transactions |
| owner console -> /admin/contract-check | Admin-only on-demand run |
| worker -> settings table | The pause writes switches; only the owner turns them back on |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10-01 | Tampering | jobs keep sending after pump changes | mitigate | Mismatch turns every switch off; forced-mismatch unit test (D-21) |
| T-07-10-02 | Denial of service | mismatch marks the platform evacuated and blocks the runbook switch | mitigate | switchesOff writes no evacuated_at; test asserts it |
| T-07-10-03 | Repudiation | automatic pause without a trace | mitigate | One admin_audit row with the facts plus a Sentry error |
| T-07-10-04 | Elevation of privilege | anyone triggering checks | mitigate | Route inside gated(); admin-routes.test.ts asserts 403 for another actor |
| T-07-10-05 | Denial of service | check never runs in genesis or engine-off mode | mitigate | Own timer, started in the listening handler, not via scheduleBatch |
| T-07-10-06 | Denial of service | flaky RPC pausing everything | mitigate | An RPC throw is "could not run" and pauses nothing |
</threat_model>
