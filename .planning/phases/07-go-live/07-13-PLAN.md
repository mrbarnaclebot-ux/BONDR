## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| creator -> worker prepare | The symbol is attacker-chosen; normalization happens before the key is used |
| worker -> Postgres | One read per prepare; Neon quota |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-13-01 | Spoofing | vamp coin reusing a fresh ticker | mitigate | 24h lock from landing, keyed by the normalized symbol; ticker.test.ts matrix |
| T-07-13-02 | Spoofing | case, $, whitespace or homoglyph tricks | mitigate | checkSymbol limits to A-Z0-9 uppercase before the read (D-41) |
| T-07-13-03 | Tampering | two prepares racing for one ticker | mitigate | prepare's single-flight queue; ponytail names the upsert upgrade for multi-replica |
| T-07-13-04 | Denial of service | refused prepares spending tables or reservations | mitigate | Refusals before caps, balance, reservation and table; prepare.test.ts asserts no spend |
| T-07-13-05 | Denial of service | squatting a ticker with prepared rows | mitigate | Prepared rows lock others only for 3 minutes and never the same wallet |
| T-07-13-07 | Tampering | a stale in-flight row freeing the ticker or a negative wait | mitigate | Refuse whenever a holding row exists; retryAfter clamped at 0; 10-minute-old unknown row test |
| T-07-13-06 | Spoofing | impersonating BONDR or stablecoins | mitigate | Reserved list refused for children; genesis bypasses only through its own path |
