## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie -> page and prepare route | The admin cookie is HMAC-sealed; only its validity is used |
| web -> worker actor | The worker re-checks actor against ADMIN_WALLET |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-18-01 | Spoofing | actor forged in the request body | mitigate | FIELDS allowlist excludes actor; actor spread last from adminSession only |
| T-07-18-02 | Elevation of privilege | the owner variant shown to a stranger | mitigate | Server-side adminSession; even if shown, the worker refuses non-admin wallets (07-16) |
| T-07-18-03 | Information disclosure | admin wallet leaked into the page | mitigate | Only a boolean prop crosses to the client |
| T-07-18-04 | Tampering | owner skipping the reserved check for a child launch | accept | The bypass is UI-only and only in genesis mode; the worker refuses reserved tickers for every child prepare |
</threat_model>
